**Σύστημα Διαχείρισης Αποθήκης και Διάσωσης (με χάρτες OpenStreetMap και Google Maps)**

Διαδικτυακή εφαρμογή για τη διαχείριση αποθήκης προϊόντων, αιτημάτων πολιτών, δωρεών και οχημάτων διάσωσης, με διαδραστικούς χάρτες. 
Η σελίδα χάρτη έχει υλοποιηθεί και με OpenStreetMap (Leaflet) και με Google Maps JavaScript API, με την ίδια λειτουργικότητα και τα ίδια δεδομένα.

Τι κάνει η εφαρμογή

Ο διαχειριστής μπορεί από το μενού της εφαρμογής να:

-διαχειρίζεται την αποθήκη προϊόντων,
-βλέπει τον χάρτη με όλα τα σημεία ενδιαφέροντος,
-δημιουργεί λογαριασμούς διασωστών,
-βλέπει στατιστικά,
-δημιουργεί ανακοινώσεις.

Ο διασώστης μπορεί να:

βλέπει στον χάρτη τη θέση του, το όχημά του (μετακινείται με drag and drop), τα αιτήματα και τις δωρεές,
αναλαμβάνει αιτήματα και δωρεές, και η διαδρομή σχεδιάζεται στον χάρτη,
διαχειρίζεται τη λίστα των tasks του (ολοκλήρωση ή διαγραφή).

Ο πολίτης μπορεί να:
κάνει αίτημα
κάνει δωρεά

Και οι δύο υλοποιήσεις παρέχουν:

τη Βάση, με marker που μετακινείται (στον διαχειριστή) και αποθηκεύεται η θέση της,
τα οχήματα, με popup/InfoWindow που δείχνει φορτίο και tasks,
τα αιτήματα πολιτών και τις δωρεές, με πληροφορίες χρήστη,
γραμμές (polylines) από κάθε όχημα προς τον προορισμό του task (μπλε για αιτήματα, πράσινες για δωρεές),
φίλτρα εμφάνισης (αναληφθέντα αιτήματα, αιτήματα σε αναμονή, μόνο δωρεές, κρυφές γραμμές κ.ά.).

Τεχνολογίες
Frontend: HTML, CSS, JavaScript (AJAX), jQuery, DataTables
Χάρτες: Leaflet με πλακίδια OpenStreetMap, και Google Maps JavaScript API (markers, InfoWindows, polylines)
Backend: PHP (sessions, endpoints JSON)
Βάση δεδομένων: MySQL
Περιβάλλον ανάπτυξης: XAMPP (Apache, MySQL)
